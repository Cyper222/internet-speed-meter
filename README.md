# Измеритель скорости интернета

Консольный скрипт на Python: принимает URL файла, выполняет **10 последовательных
GET-запросов**, каждый раз дожидается полной загрузки и выводит среднее время
запроса, общий объём скачанных данных и скорость в **МБ/с** и **Мбит/с**.

## Запуск

Нужен Python 3.9 или новее. Сторонних библиотек нет, `pip install` не требуется.

Клонируйте репозиторий и откройте его папку:

```bash
git clone https://github.com/Cyper222/internet-speed-meter.git
cd internet-speed-meter
```

Также можно скачать репозиторий через **Code → Download ZIP** и распаковать архив.
Запустите скрипт, передав ссылку на файл:

```bash
python3 speed_meter.py "https://example.com/large-image.jpg"
```

Замените пример на **прямую ссылку на существующую большую картинку или другой
файл** (желательно несколько мегабайт). `example.com/large-image.jpg` — только
образец адреса. Ссылка должна быть доступна без авторизации. Заключайте URL в
кавычки, особенно если в нём есть `&`. Для Windows можно использовать `py -3`
вместо `python3`.

Готовый пример с большой фотографией на Unsplash (около 3,3 МБ на загрузку):

```bash
python3 speed_meter.py "https://kartinkof.club/uploads/posts/2022-12/1670401826_kartinkof-club-p-kartinki-neobichnie-so-smislom-1.jpg"
```

Это внешний ресурс: его доступность и размер могут измениться.

По умолчанию таймаут отдельной сетевой операции — 30 секунд. Его можно изменить:

```bash
python3 speed_meter.py "https://example.com/large-image.jpg" --timeout 60
python3 speed_meter.py --help
```

Таймаут ограничивает ожидание подключения или данных, а не общую длительность
скачивания. Скрипт скачает файл 10 раз: файл размером 5 МБ создаст примерно
50 МБ входящего трафика без учёта служебных данных.

Пример вывода с условными результатами:

```text
 1/10: 5000000 байт, 1.000 с
 2/10: 5000000 байт, 1.000 с
 ...
10/10: 5000000 байт, 1.000 с

Завершено запросов: 10
Среднее время запроса: 1.000 с
Скачано: 50000000 байт (50.000 МБ)
Скорость: 5.000 МБ/с (40.000 Мбит/с)
```

## Как считается скорость

Для каждого запроса `time.perf_counter()` измеряет время от начала подключения
до полного чтения тела ответа. Файл читается блоками по 64 КиБ, не сохраняется
на диск и не загружается целиком в память. Объём считается по фактически
прочитанным байтам тела ответа, а не по заголовку `Content-Length`.

```text
Среднее время = сумма длительностей / 10
Скорость, МБ/с = сумма скачанных байт / сумма длительностей / 1 000 000
Скорость, Мбит/с = скорость в МБ/с × 8
```

1 МБ = 1 000 000 байт. Скорость вычисляется по общему объёму и общему времени,
а не как среднее арифметическое десяти скоростей.

Измеряется скорость загрузки с выбранного сервера с учётом задержек подключения,
TLS, перенаправлений и ожидания ответа. Она зависит от сервера, маршрута и размера
файла и может отличаться от максимальной скорости тарифа. Скрипт не использует
локальный кэш, запрашивает ответ без сжатия и отправляет заголовки против
кэширования; поведение серверного кэша определяется самим сервером.

HTTP-перенаправления обрабатываются автоматически: это остаётся десятью
последовательными загрузками, но сетевых запросов может быть больше десяти.
Для ровно десяти HTTP-запросов используйте конечный URL файла.

При HTTP-ошибке, обрыве соединения, пустом ответе или таймауте скрипт завершится
с кодом `1`, сообщит номер запроса и не выведет итоговую скорость по неполной
серии. Некорректные аргументы дают код `2`, прерывание Ctrl+C — `130`.
